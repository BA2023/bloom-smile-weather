# BLOOM · 笑意有回响

表情驱动的直播间 AR 原型：微笑下雨，大笑绽放烟花，移动头部与粒子碰撞互动。

- [在线 Demo](https://bloom-smile-weather.vercel.app/)
- 运行代码基线：`interaction-audit-105`，部署提交 `8edea3616b30b7c9802b9cfcd005c7d17cc49de8`。
- 最新验证：108 项自动化测试通过；完整范围见 [ACCEPTANCE.md](ACCEPTANCE.md)。

## 快速运行

需要 Node.js 20+。构建与测试不需要额外 npm 依赖；首次 setup 从锁定地址下载模型、SDK 和 WASM，并校验 SHA-256。

```sh
git clone https://github.com/BA2023/bloom-smile-weather.git
cd bloom-smile-weather
npm run setup
npm test
npm run build
npm run dev
```

浏览器打开终端显示的 `http://127.0.0.1:4173`。公开部署需 HTTPS。`dist/` 为静态产物，支持相对路径托管。模型运行资源构建后与网页同源提供。

## 当前体验

| 项目 | 行为 |
| --- | --- |
| 首次进入 | 请求本机前置摄像头，需要浏览器授权；AI 主播默认关闭 |
| 默认特效 | Gemini、随机配色；已有有效的 GPT/Gemini 风格选择会保留 |
| 表情 | 平静等待、微笑下雨、大笑烟花；大笑使用嘴角上扬和张嘴幅度的视觉代理 |
| 头部互动 | 四点拟合旋转椭圆，粒子与头部轮廓碰撞、弹开 |
| 手动预演 | 平静3秒、细雨4秒、烟花一轮；重复点击重播，其他按钮替换，结束恢复原输入 |
| AI 主播 | 虚构成人的10秒无声分镜，特效按脚本演示；开启时释放真实镜头，关闭时回到镜头 |
| 体验设置 | GPT/Gemini 风格、配色、两版独立灵敏度、头部光环、简化特效 |
| 固定参数 | 放大粒子和自然落雨，已移除对应对比控件 |
| 语言 | 中文/英文切换，浏览器记忆选择；用户评论保留原文 |

桌面为居中的9:18.2竖屏舞台与左右控制、参数面板。手机默认只显示铺满可视区域的直播间；右侧“面板”打开与电脑版共用的六张卡片。三态预演、来源切换后自动收起面板。浏览器自己的地址栏/工具栏受系统控制；支持时可手动进入全屏或添加到主屏幕。

顶部胶囊区分镜头、手动预演和AI脚本来源，展示当前表情与实际特效。右侧实时参数区分真实测量与演示数据，FPS不固定为60。关注、评论、观看人数、礼物与点赞均是本机模拟，不连接TikTok、不收费、不发送真实社交消息。

## 实现与性能取舍

- 原生 ES Modules、Canvas 2D、MediaPipe Face Landmarker；视频仅在本机处理，不上传，不申请麦克风。
- Gemini独立SDK/GPU识别；GPT首选经典Worker、单帧在途，兼容回退主线程低频推理。切换特效复用镜头，不重复申请摄像头。
- 识别与绘制分频，系数平滑、迟滞和冷却抑制误触。两版灵敏度独立保存于本次会话。
- 烟花采用顶点求解、球面方向扩散、阻力、重力和燃尽；近景为有界的细光迹与圆形亮核。
- 连续线段与旋转椭圆碰撞避免高速穿透；位置修正、速度上限与碰撞余燃限制能量。
- 预分配粒子池、数量上限、有限生命周期、DPR上限及低帧率降级控制开销；简化特效降低雨/烟花数量并暂停AI分镜，仍可手动预演。
- 隐藏页面暂停推理与动画；停止、退出或离开时释放媒体与模型。缓存返回时按原来源恢复，清理旧请求与提示，评论定时器只启动一次。

Gemini视觉与识别基于用户提供的参考原型迁移并集成；两版共用部分改进后的烟花运动求解器。完整参考、差异和许可记录见 [FIREWORKS_REFERENCES.md](FIREWORKS_REFERENCES.md)。AI素材来源见 [MEDIA_PROVENANCE.json](MEDIA_PROVENANCE.json)。

## 验证与边界

108项自动化测试覆盖表情状态、物理轨迹、连续碰撞、色彩继承、性能计量、语言、源切换、预演、权限取消、缓存恢复及响应式状态。Chrome检查覆盖桌面、320×568、390×844和667×375视口，包括分享、六卡片抽屉、英文说明和退出重进。

候选人曾反馈真人体验未发现明显问题，但未记录设备、时长与量化性能，不能作为当前版本的完整真机基准。手机镜头首次开启时偶尔未铺满仍为已知问题。视口模拟、自动化测试与脚本AI演示不替代真实手机摄像头、浏览器工具栏和识别延迟测试。

头部轮廓为近似椭圆，不是完整头发/耳朵分割；“大笑”为可见表情代理，不是声音或真实情绪识别。Gemini保留参考实现的部分丢脸信号保持行为。测试操作见 [TEST_GUIDE.md](TEST_GUIDE.md)，历史纠偏见 [DEVELOPMENT_LOG.md](DEVELOPMENT_LOG.md)。

## 复盘（200字以内）

**遇到的问题：** AI 对预演逻辑理解有偏差：切换到 Gemini 后，雨和烟花同时出现，观众难以理解表情与特效的对应关系。

**指令干预与结果：** 纠偏 Prompt（整理）：“请统一两种特效风格的预演逻辑：切换后清除残留特效，按平静、微笑下雨、大笑烟花依次循环；每个状态只显示对应效果，避免雨与烟花同时出现。”调整后，两种风格均从平静开始，依次展示对应特效，预演逻辑保持一致。
