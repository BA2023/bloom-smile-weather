# BLOOM — 笑意有回响

一个由表情驱动的 AR 互动原型。微笑时落下流光细雨，大笑时绽放层叠星焰，烟花粒子与头部轮廓碰撞、反弹。支持鎏金、绯樱、极光三种配色。

在线体验：<https://bloom-smile-weather.freesnipe20.chatgpt.site>（无需登录；摄像头由浏览器请求授权）

## 运行

需要 Node.js 20+，构建和测试无额外 npm 依赖。先运行一次 `npm run setup`，从固定上游地址下载识别运行库、WASM 和模型，并根据 `assets.lock.json` 校验 SHA-256。构建后这些资源与网页同源托管，体验时无需向外部 CDN 请求识别模型。仓库不提交大型生成资源；锁文件与下载脚本可复现线上版本。

```sh
git clone https://github.com/BA2023/bloom-smile-weather.git
cd bloom-smile-weather
npm run setup
npm test
npm run build
npm run dev
```

访问终端显示的 `http://127.0.0.1:4173`。线上使用 HTTPS。`dist/` 是可直接托管的静态产物，使用相对路径，支持部署到子目录。

## 体验

默认进入标明“模拟直播间”的9:16预览。顶部有主播信息、关注和观众示意；底部为评论输入、分享及礼物入口，右侧可点赞、看到飘心。点击礼物图标，选择“流光细雨”“流光烟花”或“心动”；送礼面板关闭后显示礼物通知和对应效果。烟花忙碌时最多保留一次待触发请求，避免礼物被忽略或无限堆积。

评论、观看人数、关注与礼物均为浏览器本地模拟，不连接TikTok，不充值、不发送真实消息。评论以纯文本显示、最多保留4条；分享按钮可复制当前Demo链接；离开后可重新进入。

点击舞台右上方“开启镜头”并授权，加载完成后进入实时互动。微笑触发雨，强微笑结合张口持续触发烟花；头部可以接住星光。镜头模式中手动赠送细雨持续6秒，独立于表情信号。关闭镜头或离开预览会释放媒体轨道、模型与Worker。

表情灵敏度、调试信息与轻量动效位于“体验设置”。开启调试可查看真实表情系数、推理耗时、粒子数、碰撞数和当前推理路径。

## 视觉设计

- 深色舞台与低饱和界面，让镜头和特效成为视觉中心。
- 雨景由远景细线、中景流光、近景大水滴组成；薄雾、冷暖色高光与双层椭圆涟漪构成一场有景深的光雨。
- 烟花由升空光迹、主花、错时伴生花、冷色内环、闪烁余辉构成；额外的透视前景星轨在9:16画面内朝镜头加速、放大，形成迎面飞来的景深。
- 星轨保留固定长度历史，碰撞后轨迹能够自然转折；不依赖全屏模糊和无限粒子堆叠。
- 色彩有三组受控方案：香槟金与淡玫瑰、粉紫与暖白、薄荷青与极光紫。

## 手机优先

- 所有设备使用9:16竖屏舞台，预览在页面水平中线。宽屏采用说明、预览、手机扫码入口三栏；窄屏优先展示居中的直播预览，配色与设置置于下方。首次访问与无锚点刷新回到预览顶部。
- 镜头开关位于舞台上方；评论、分享和礼物栏位于舞台底部；配色与设置位于手机舞台下方。
- 主花与伴生花采用原有构图；每根星轨加粗至约1.5–2.3 CSS像素，并以柔光边缘强化可见度，20点历史让短光线更长。
- 烟花按竖屏标定范围；透视前景与主烟花均在手机舞台内裁切，不产生横向滚动、不拦截按钮与手势。

## 技术与边界

- 原生 ES Modules、Canvas 2D、MediaPipe Face Landmarker。
- 使用 `mouthSmileLeft` / `mouthSmileRight` 的均值及 `jawOpen`，组合平滑、迟滞、持续时间、冷却和重新武装条件。“大笑”是可见表情代理，不是音频或真实情绪识别。
- 默认单人脸。四个关键点拟合并外扩旋转椭圆，近似可见头部范围；这不是完整头发/耳朵分割或三维刚体。
- 同一坐标函数处理 `object-fit:cover`、镜像和舞台尺寸；物理以 CSS 像素计算，DPR 仅影响渲染清晰度。
- 连续线段与椭圆求交防止高速穿透；反射、阻尼、有限头部速度和表面投影约束碰撞能量。
- 首选经典 Worker 内动态加载模型，因为当前固定版本 WASM 加载器调用 `importScripts`。不兼容设备回退到主线程低频推理，界面可查看真实路径。
- 视频帧单在途，Worker 识别约每 75ms 最多一次，回退约每 130ms 最多一次；所有视频帧在浏览器本机处理，不上传。
- 主粒子使用预分配数组池与有限生命周期；轨迹历史固定20点。默认桌面上限1350、窄屏850，持续低帧率时下调，DPR上限1.6。前景透视星轨另设100条硬上限、涟漪30个上限，轻量模式关闭透视前景层并降低雨量。
- 页面隐藏时停止推理与动画推进；停止体验或离开页面时释放摄像头、模型和 Worker。默认不申请麦克风。

## 验证

详见 `ACCEPTANCE.md`。本轮已运行 10 项核心测试（含透视加速、视野边缘与数值稳定性），以及输入静态肖像的合成视频链路，验证真实模型加载、Worker 推理、面部检测与停止释放。该测试不等于真人微笑、大笑和真实手机摄像头测试；这些仍需用户真机验收。

本地浏览器测试页可通过以下命令准备，输入一张本地肖像供模型验证，仅复制到被忽略的构建目录：

```sh
node scripts/prepare-browser-qa.mjs /absolute/path/to/portrait.png
```

重新 `npm run build` 会清理这些测试页面。最终发布构建不包含题目图集或测试肖像。

## 手机访问

公开HTTPS链接可直接在手机浏览器打开：https://bloom-smile-weather.freesnipe20.chatgpt.site/ 。桌面页面提供静态二维码与复制手机链接按钮，二维码由qrcode 8.2离线生成，不调用外部二维码服务。手机页面保持9:16，处理安全区域，文本输入为16px。镜头需用户点击授权，默认前置摄像头、playsinline与本机识别。

浏览器CSS视口检查覆盖1280×720、1440×900、906×989、320×568、360×800、390×844、430×932。上述不等于真人摄像头或真实手机硬件性能实测。
